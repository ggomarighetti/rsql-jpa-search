The exports preserve the original labels, geometry, and embedded styles. Each
file adds the SVG namespace, explicit dimensions, an accessible title and
description, and 16 units of padding with a white background so the original
dark labels remain legible in both light and dark README viewers. They do not
load fonts, styles, scripts, or images from the blog.

To refresh an image, extract the corresponding inline SVG from the article,
retain its embedded styles and internal IDs, and apply the same standalone
wrapper. Check it as an image embedded in the README, including on a narrow
screen, before replacing the export. Keep the source URL and export date in
the SVG comment and this file up to date.
